# Teacher Images Directory

Place your teacher profile images in this directory (`public/assets/teachers/`).

### Recommended Image Filenames:
- **Combined Maths Teacher**: `combined-maths.jpg` (or `.png` / `.webp`)
- **Physics Teacher**: `physics.jpg` (or `.png` / `.webp`)
- **Chemistry Teacher**: `chemistry.jpg` (or `.png` / `.webp`)
- **Biology Teacher**: `biology.jpg` (or `.png` / `.webp`)

### Alternate standard filenames:
- `sarah-lin.jpg`
- `marcus-sterling.jpg`
- `aris-thorne.jpg`
- `evelyn-vance.jpg`

If an image is not yet uploaded, the website will automatically display a high-tech fallback avatar with teacher initials and gradient styling.
